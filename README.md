# Aqsat — مدیریت جامع اقساط و بدهی‌ها

## Android
پروژهٔ Android Studio در پوشهٔ `AqsatApp/` قرار دارد. فایل ZIP اصلی نیز با نام `AqsatApp.zip` در ریشهٔ مخزن نگهداری می‌شود.

### ساخت APK
با هر push به شاخهٔ `main` که فایل‌های Android یا workflow را تغییر دهد، GitHub Actions برنامهٔ Android را با Java 17 و Gradle 8.7 می‌سازد. اجرای دستی نیز از زبانهٔ Actions و workflow با نام **Android APK** ممکن است.

خروجی در بخش Artifacts اجرای موفق با نام `Aqsat-debug-apk` قابل دریافت است. این workflow فعلاً APK آزمایشی (debug و بدون امضای انتشار) تولید می‌کند.

## نکات فنی نسخهٔ ZIP
- رابط کاربری در `app/src/main/assets/index.html` و پوستهٔ اندروید در Kotlin/WebView است.
- داده‌ها در `localStorage` مرورگر WebView ذخیره می‌شوند؛ پاک‌کردن داده‌های برنامه یا حذف نصب می‌تواند آن‌ها را از بین ببرد، بنابراین از پشتیبان‌گیری JSON استفاده شود.
- کتابخانه‌های خروجی تصویر و Excel و فونت Vazirmatn از CDN بارگیری می‌شوند؛ این قابلیت‌ها در حالت کاملاً آفلاین ممکن است در دسترس نباشند.
- اعلان‌ها با AlarmManager زمان‌بندی می‌شوند و در نسخهٔ فعلی تضمین دقیق‌بودن زمان اعلان وجود ندارد.
